# 测量与迭代

## 指标口径

按审计目标选指标。每项写明正类、分子、分母、排除项和 `unknown`、`error` 的处理。报告计数与比率，并描述被弃判和排除样本的构成。使用不同可比较分母时同时报告覆盖率和固定样本的结果。

对二元任务，常用口径如下。由实验问题决定是否采用。

| 指标 | 分子与分母 |
| --- | --- |
| 误放行率 | E 判成功且参考判失败的数量，除以双方均有判定的参考失败数 |
| 误拒率 | E 判失败且参考判成功的数量，除以双方均有判定的参考成功数 |
| 可比较覆盖率 | 双方均有判定的案例数，除以预先纳入的全部案例数 |
| 弃判率与执行错误率 | E 的 `unknown` 和 `error` 各自的案例数，分别除以 E 应评分的案例数 |

分母为零时报告不可估计。另报 oracle 缺失或未定的比例。比较改动时核对弃判、错误和排除项的变化，必要时按不同未知项取值报告决策界限。精度变化须与覆盖率和样本构成一同解释。

其他可选指标包括最小对照区分力、无关变换稳定性、关键切片错判、系统差异与排序变化、发布决策、评分耗时、费用和维护负担。按预先声明的决策用途分别解释，只有存在明确定义且经核验的损失函数时才考虑合成。

有统计推断时说明抽样框、独立性和缺失假设。使用与抽样一致的分析单位，保留同任务、模板或案例族内的相关性。小样本主要用于识别机制。挑战集上的比例适用于其构造样本，估计生产误判率需要目标分布样本。比较方法使用同一批案例、同一参考和明确的预算口径。比较排序先定义参考排序、集合、权重及不确定性，再检查结论是否随指标、缺失情况或阈值改变。

## 修复与留出验证

针对已获支持的机制提出最小修复，例如补采状态证据、修改规则或解析、检查约束、调整采样和统计方法、校准裁判或收窄声明。说明对应 `H_ID`、预期收益、额外成本和可能新增的错判。

保持目标契约和独立参考固定，优先在同批冻结轨迹配对重评 `E_old`、`E_new`，隔离评测方法变化。契约或 oracle 变更时单独版本化、解释变化并重新建立可比基准。预先固定可接受的判定覆盖、错误率与成本要求。验证已知坏例、原有正确样本、合法替代路径和未见实体、表达、模板或环境。

按源任务、模板和失效机制检查组间重叠后划分开发与保留样本。同源案例的措辞改写留在同一侧。保留集仅用于独立验收，一旦查看结果并据此调整方法，转为开发数据并补充新的保留集。记录修复验证发生在开发集还是独立保留集。

## 数据集与版本记录

| 集合 | 目的 |
| --- | --- |
| 代表集 | 估计目标分布表现，记录抽样框和权重 |
| 挑战集 | 主动寻找失效机制，保留干预和控制条件 |
| 回归集 | 防止已知问题复发，保留对应 `H_ID` 和修复版本 |

独立管理三类集合。新增案例、修改阈值和变更题集保留版本、理由、变更内容和证据。纵向比较使用固定锚点集，新增集单独报告。分别解释题集变化带来的结果差异与固定条件下的性能变化。
